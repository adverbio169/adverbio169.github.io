===============================================================================
O QUE SO VOCE PODE FAZER
===============================================================================
Criar a conta e autenticar. Nao manuseio token nem senha, e conta e ato seu.
O resto ja esta feito.

===============================================================================
PASSO 1 - CRIAR O REPOSITORIO VAZIO (navegador, ~2 min)
===============================================================================
  1. github.com -> New repository
  2. Nome: comissao-subsidio
     ATENCAO: o nome entra no endereco, e o endereco vai impresso no relatorio.
  3. Visibilidade: Public  (o Pages gratuito so publica repositorio publico)
  4. NAO marque nada em "Initialize this repository" - nem README, nem .gitignore
  5. Create repository

===============================================================================
PASSO 2 - MANDAR OS ARQUIVOS (terminal, DENTRO desta pasta)
===============================================================================
Abra o terminal nesta pasta e rode as duas linhas, trocando SEU-USUARIO:

    git remote add origin https://github.com/SEU-USUARIO/comissao-subsidio.git
    git push -u origin main

Na primeira vez o Git abre uma JANELA DO NAVEGADOR para voce entrar no GitHub.
Nao ha senha para digitar no terminal. Sao 27 MB: o push leva um ou dois minutos.

===============================================================================
PASSO 3 - LIGAR O PAGES (navegador, ~1 min)
===============================================================================
  1. No repositorio: Settings -> Pages
  2. Source: "Deploy from a branch"
  3. Branch: main   /   (root)   -> Save
  4. Espere ~1 minuto e recarregue. O endereco aparece no alto.

Abra o endereco para conferir: tem de aparecer o cartao azul com o botao
"Abrir o painel interativo", e o botao tem de abrir o painel.

===============================================================================
PASSO 4 - ME MANDE O ENDERECO
===============================================================================
Com o endereco no ar e conferido, me passe a URL. Eu gero o QR Code e o cartao
no padrao visual do relatorio e devolvo a imagem aqui, para voce inserir no
documento e exportar o PDF de novo.

*** NAO GERE O QR ANTES DE O ENDERECO ESTAR NO AR. *** QR impresso e irreversivel.

===============================================================================
DEPOIS: O PDF PRECISA SER TROCADO UMA VEZ
===============================================================================
O QR entra DENTRO do relatorio. Entao a ordem e:
   publica -> sai o endereco -> entra o QR no documento -> exporta o PDF de novo
   -> substitui o PDF aqui e da push.
O endereco nao muda nesse processo, entao o QR ja impresso continua valido.

===============================================================================
COMO ATUALIZAR QUALQUER COISA, SEMPRE
===============================================================================
Substituir o arquivo mantendo o nome, e:

    git add -A
    git commit -m "atualizacao"
    git push

O Pages republica sozinho em cerca de um minuto.

Para refazer esta pasta a partir dos arquivos de trabalho (depois de um rebuild
do painel ou de um export novo do PDF), peca: existe um script que copia tudo e
renomeia o painel.

===============================================================================
SE UM DIA A TI DO ESTADO LIBERAR O DOMINIO
===============================================================================
NAO reimprima nada. Abra o index.html, ache a linha

    var DESTINO = "";

e preencha com o endereco novo:

    var DESTINO = "https://dominio-do-estado/comissao-subsidio/";

commit, push. Todo QR Code ja impresso passa a levar ao endereco novo. E para
isso que a pagina de entrada existe.
